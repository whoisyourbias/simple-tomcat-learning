# 0단계: 빌드 환경 구성 계획

2026-11-05. 사용자가 명시적으로 요청한 0단계만 구현한다. 기준은 [준비 절차](../reference/03-learning-workflow.md)다.

## 범위와 작업 순서

1. JDK 21 설치 위치와 Maven 부트스트랩 환경을 확인한다.
2. Maven 3.9.9·Wrapper 3.3.2를 고정하고 Windows·POSIX 스크립트를 제공한다.
3. JUnit Jupiter 5.11.4, Compiler 3.13.0의 release 21, Surefire 3.5.2, JAR 3.4.2를 설정한다.
4. 실행 JVM이 21이고 시스템 컴파일러가 존재하는지 환경 테스트로 확인한다.
5. 관련 테스트·전체 clean verify·JAR 내용 확인 후 학습 문서·현재 상태를 갱신한다.
6. 설정·테스트·문서를 함께 커밋하고 learn/step-00 태그를 생성한다.

완료 조건은 환경 테스트 통과와 JAR 생성이다. 서버·main 클래스는 이 단계에 없으며 실행 가능한 서버 JAR은 7단계 범위다. HTTP 실험은 서버가 생기는 1단계부터 적용한다. 이 예외는 환경만 구성하는 기존 준비 절차에 근거한다.

## Tomcat 고정 소스와 차이

[Tomcat 10.1.34 build.xml](https://github.com/apache/tomcat/blob/10.1.34/build.xml)의 최상위 초기화에서 build.properties 계열을 읽고 Ant 버전, Java 빌드 버전을 검사한다. compile.release=11, min.java.version=11, build.java.version=17을 확인했다. 이 단계는 빌드 설정만 대응하며 요청 처리 메서드·연결 상태·소켓 소유권·종료 처리는 아직 구현하지 않는다. 해당 근거는 1단계 이후 조사한다.

| 항목 | 실제 동작 | 프로젝트 동작 | 이유 | 영향 | 검증 | 후속 여부 |
|---|---|---|---|---|---|---|
| 빌드 도구 | Ant build.xml에서 설정 로드 후 버전 검사 | Wrapper → Maven compile → JUnit test → JAR package → verify | 작은 단일 모듈의 공통 명령 제공 | Tomcat 빌드를 재현하는 프로젝트는 아님 | Wrapper 버전·clean verify | Maven 유지 |
| Java 기준 | 컴파일 대상 11·최소 실행 11·빌드 17 이상 | release 21·테스트 JVM 21·시스템 컴파일러 확인 | 학습 환경 고정 | 다른 주 버전에서는 테스트 실패 | 환경 테스트 2개 | JDK 21 유지 |
| 산출물·자원 | 배포 산출물은 별도 Ant 대상에서 구성, 상세 미조사 | 애플리케이션 코드 없는 일반 JAR, Maven이 target 생성·clean 정리 | 서버 구현 이전의 패키징 확인 | java -jar 실행 불가·HTTP 검증 대상 없음 | jar tf·clean verify | 서버 1단계, 실행 JAR 7단계 |

실행 결과는 계획의 예정 조건과 구별해 [0단계 실행 기록](../00-overview/03-step-00-setup.md)에 남긴다.
